# Beauli Frontend Demo

Простий клієнт для демонстрації отримання даних із каталогу Beauli API та роботи CORS.

## Адреси та порти
* **Бекенд (Django API):** `http://127.0.0.1:8000`
* **Фронтенд:** `http://127.0.0.1:5500`

## Як запустити проєкт
1. Запустіть бекенд-сервер Django на порті 8000 (`python manage.py runserver`).
2. Для запуску фронтенду використайте будь-який локальний HTTP-сервер:
   * **Через Python:**
     ```bash
     python3 -m http.server 5500
     ```
   * **Через VS Code / PyCharm:** відкрийте `index.html` за допомогою розширення Live Server або вбудованого браузера.
3. Відкрийте у браузері `http://127.0.0.1:5500`.
