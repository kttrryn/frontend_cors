# Beauli Cosmetics Frontend Client

Клієнтський SPA-застосунок на HTML, CSS та Vanilla JavaScript для взаємодії з REST API Beauli Store.

## Функціонал

1. **Реєстрація та Логін**:
   - Валідація обов'язкових полів, формату email, мінімальної довжини пароля та їх збігу.
   - Отримання та збереження JWT пари токенів (`access` та `refresh`) у `localStorage`.
2. **Публічна сторінка**:
   - Каталог товарів (`/products`) доступний без авторизації.
3. **Захищена сторінка**:
   - Панель створення нового товару доступна лише авторизованим користувачам з дійсним `access` токеном.
4. **Маршрутизація та перенаправлення**:
   - Спроба перейти на захищену сторінку без логіну редіректить на форму входу із запам'ятовуванням сторінки. Після входу повертає користувача назад.
   - Авторизованого користувача перенаправляє з форми логіну до каталогу.
   - Динамічна шапка: неавторизований бачить кнопку «Вхід», авторизований — своє ім'я та кнопку «Вийти».
5. **Безшовне оновлення токенів (JWT Refresh)**:
   - При отриманні `401 Unauthorized` клієнт автоматично робить запит на ендпоінт `/api/v1/auth/token/refresh`, оновлює токен і повторює запит без повторного логіну.

## Адреси та порти

* **Бекенд (Django API):** `http://127.0.0.1:8000`
* **Фронтенд:** `http://127.0.0.1:5500`

## Як запустити проєкт

1. Переконайтеся, що бекенд-сервер запущено:
   ```bash
   python manage.py runserver 8000
   ```
2. У папці фронтенду запустіть будь-який локальний HTTP-сервер на порту 5500:
    ```bash
    python3 -m http.server 5500
    ```
3. Відкрийте браузер за адресою: http://127.0.0.1:5500.
